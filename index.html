STREET GOAL

Choose a prototype version to play. Each version adds new mechanics on top of the previous one.

Version 0 Perspective Earliest prototype: perspective camera, joystick movement, swipe-to-shoot, and basic goal scoring — no timer or sectors. Version 1 Classic Original arcade loop: joystick movement, swipe to shoot, curved shots, 2×2 sector respawns, and 30-second rounds. Version 2 Features Adds NES-style player sprite, dribble-touch mechanic, quadrant ×2 bonus, Level 2 with goal target zones and a goalkeeper. Version 3 Tuned Smaller, smoother player resize range and a gentler dribble nudge with a 600 ms cooldown. Version 4 Attached Ball stays attached during the cooldown, smaller 1.02x nudge, constant friction, lighter goal gravity, tighter sprite scale, and bigger kick radius. Version 5 Portrait Tuned for 16:9 portrait: higher camera, bigger field, corrected sprite resize, 1.05x nudge, slower keeper with 45% save rate. Version 6 Physics Wider 4:6 field, keeper roams a goal-area box, and swipe speed=height / length=distance for chip vs. ground shots. Version 7 Balanced Squarer field, fixed sprite perspective, and kick power scales down near the goal. Version 8 Refined Gentler kick modulation (65%/85%), field shifted up, faster player, stronger nudges, keeper matches player size. Version 9 Stadium Deeper field, stadium with crowd, fixed repeating dribble touches, red edge pulse and clock ticks when time runs out, kick and save sounds. Version 10 Pace Faster player with perspective-scaled speed, gentler kick strength modulation near the goal. Version 11 Aim + Chase Simpler swipe mechanics (short chip, long drive, speed = strength), aim assist, score-chase level with stopwatch. Version 12 Pick-up Boost Swipe closer to early versions, lighter aim assist, pick-up ⚡ power-up boost, keeper added to score-chase. Version 13 Tutorial New tutorial level, pick-up ⚡ boost, keeper throws farther after saves, Level 1 clearly highlights pickup and kick-from segments. Version 13A Kick v10 Same as v13, but uses the Version 10 kick mechanics (speed = z, length = xy, 75%/90% modulation). Version 13B Kick v9 Same as v13, but uses the Version 9 kick mechanics (speed = z, length = xy, 65%/85% modulation). Version 13C Kick v1 Same as v13, but uses the original Version 1 kick mechanics (speed = power, straight arc, no modulation/aim assist). Version 14 Tap Field No joystick — tap anywhere on the field to move, swipe anywhere to shoot. Goal chime, +10% player-ball interaction box. Version 15 Zones + v1 Kick CHIP/DRIVE/LOW zones; power blends swipe speed + length with light aim assist. Deeper keeper box with depth-following; ground-shot saves at 60%. Version 16 Tug of War Two balls, two opponents. Red STEAL button to rob the bot. Tug-of-war scoring: reach +3 lead. Goalkeeper patrols randomly and is less responsive.
